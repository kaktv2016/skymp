- **REFACTOR before reuse:** APIs/lifecycle/authority need material changes before importing.

Effort is engineer-days for one experienced developer including adaptation and targeted verification; ranges overlap, exclude art/mod content and test-machine logistics. “Deferred” is not approval to implement.
